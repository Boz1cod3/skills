## Что сравнить после

```bash
python3 tools/measure-run.py "$HOME/Documents/VScode/Autopilot 2 test"
```

1. **Итог и доли по ролям** против таблицы выше. Ожидание: ревью + ремонт заметно ниже 26 %, оркестратор ниже 37 %.
2. **Время** — по дашборду прогона (`.autopilot/dashboard.html`): «в работе» против 110 минут.
3. **Качество** — блок «Слепая приёмка» на дашборде и раздел «Открытые вопросы» в отчёте: сколько требований подтверждено и сколько расхождений.
4. **Сработали ли правила**: ревью до коммита было только у фундамента и рискованных тасков; дозапросы несли только блокирующее; `state.js` не правился руками (в логе оркестратора нет Edit по `state.js`); в конце было одно ревью всей ветки.
